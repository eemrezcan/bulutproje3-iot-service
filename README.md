# IoT Service

Akilli Sehir Yonetim Platformu icin sensor verisi servisidir.

## Sorumluluk

- MQTT ile sentetik sensor verisi alir.
- Sicaklik, nem, hava kalitesi ve trafik verilerini saklar.
- DynamoDB Local / Amazon DynamoDB kullanir.
- Frontend'e REST API ile son ve gecmis sensor verilerini sunar.

## Lokal Port

Docker Compose ile `8001` host portundan erisilir.
